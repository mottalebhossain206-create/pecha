Why Pecha?

Direct /proc & /sys Parsing

Leverages Linux virtual filesystems directly for maximum speed and zero heavy dependencies.

Battery & Power Status

Real-time battery percentage tracking and time estimation for discharge or full charge cycles.

Advanced Process Table

Displays active processes sorted by resource usage including PID, user, status, resident memory, and command.

Installation Guide

# 1. Clone the repository

git clone https://github.com/mahmudul626/pecha.git

cd pecha

# 2. Compile from source

make

# 3. Install globally (optional)

sudo make install

Prerequisites

  • Linux-based operating system
  • gcc compiler
  • make utility

Uninstallation

To remove the installed binary from the system:

sudo make uninstall

Data Sources & Architecture

CPU/HW

Hardware & CPU

Parsed from /proc/cpuinfo, /sys/class/dmi/id/product_name, and GPU system info files.

MEM/DISK

Memory & Disk

Information extracted from /proc/meminfo and statvfs system calls.

PROC

Process Management

Iterates over PID directories under /proc and reads their /status files.

POWER

Power & USB

Reads from /sys/class/power_supply/ and enumerates hardware devices from /sys/bus/usb/devices/.
